Chemistry — Fraction Balancing Drill

ANSWER KEY · Unit 6.1

Technique: Save O2 for last. If you need an odd O count, write a fractional O2 coefficient, then multiply every coefficient by the denominator to clear it.

Worked Example

H2 + O2 → H2O

Step 1. Balance H → 1 H2O gives 2 H ✓

Step 2. Right has 1 O, O2 supplies 2 → write ½ O2:

H2 + ½ O2 → H2O

Step 3. × 2 to clear the fraction:

2H2 + O2 → 2H2O

Check: H = 4 = 4 ✓ O = 2 = 2 ✓

Solutions

Q1. Practice — same move 5 pts

___ S + ___ O2 → ___ SO3

Step 1. Balance S → 1 SO3 per S ✓

Step 2. Right has 3 O → need 3/2 O2:

S + 3/2 O2 → SO3

Step 3. × 2 to clear:

Check: S = 2 = 2 ✓ O = 6 = 6 ✓

Final answer

2S + 3O2 → 2SO3

Q2. Build up (acetylene) 7 pts

___ C2H2 + ___ O2 → ___ CO2 + ___ H2O

Step 1. Balance C → 2 CO2

Step 2. Balance H → 1 H2O

Step 3. O on right = 2(2) + 1 = 5 → need 5/2 O2:

C2H2 + 5/2 O2 → 2CO2 + H2O

Step 4. × 2 to clear:

Check: C = 4 = 4 ✓ H = 4 = 4 ✓ O = 10 = 10 ✓

Final answer

2C2H2 + 5O2 → 4CO2 + 2H2O

Q3. Full combustion (ethane) 8 pts

___ C2H6 + ___ O2 → ___ CO2 + ___ H2O

Step 1. Balance C → 2 CO2

Step 2. Balance H → 3 H2O

Step 3. O on right = 2(2) + 3 = 7 → need 7/2 O2:

C2H6 + 7/2 O2 → 2CO2 + 3H2O

Step 4. × 2 to clear:

Check: C = 4 = 4 ✓ H = 12 = 12 ✓ O = 14 = 14 ✓

Final answer

2C2H6 + 7O2 → 4CO2 + 6H2O
