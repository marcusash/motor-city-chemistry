Worked Example — The Fraction Move
H₂ + O₂ → H₂O
Step 1. Balance H → 1 H2O gives 2 H ✓
Step 2. Right has 1 O, O2 supplies 2 → write ½ O2: H₂ + ½ O₂ → H₂O
Step 3. × 2 to clear the fraction: 2H₂ + O₂ → 2H₂O
Check: H = 4 = 4 ✓ O = 2 = 2 ✓

Problem 1 — Practice, same move
___ S + ___ O₂ → ___ SO₃
Step 1. Balance S → 1 SO3 per S ✓
Step 2. Right has 3 O → need 3/2 O2: S + 3/2 O₂ → SO₃
Step 3. × 2 to clear: 2S + 3O₂ → 2SO₃

Problem 2 — Build up (acetylene)
___ C₂H₂ + ___ O₂ → ___ CO₂ + ___ H₂O
Step 1. Balance C → 2 CO2
Step 2. Balance H → 1 H2O
Step 3. O on right = 2(2) + 1 = 5 → need 5/2 O2: C₂H₂ + 5/2 O₂ → 2CO₂ + H₂O
Step 4. × 2 to clear: 2C₂H₂ + 5O₂ → 4CO₂ + 2H₂O
Check: C = 4 = 4 ✓ H = 4 = 4 ✓ O = 10 = 10 ✓
2C₂H₂ + 5O₂ → 4CO₂ + 2H₂O
Problem 3 — Full combustion (ethane)
___ C₂H₆ + ___ O₂ → ___ CO₂ + ___ H₂O
Step 1. Balance C → 2 CO2
Step 2. Balance H → 3 H2O
Step 3. O on right = 2(2) + 3 = 7 → need 7/2 O2: C₂H₆ + 7/2 O₂ → 2CO₂ + 3H₂O
Step 4. × 2 to clear: 2C₂H₆ + 7O₂ → 4CO₂ + 6H₂O
Check: C = 4 = 4 ✓ H = 12 = 12 ✓ O = 14 = 14 ✓
2C₂H₆ + 7O₂ → 4CO₂ + 6H₂O
