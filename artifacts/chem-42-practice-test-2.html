THE BIG RULE: When do you use prefixes (mono-, di-, tri-)?
Ionic (metal + nonmetal): NEVER use prefixes. Just say the metal name + nonmetal-ide. The charges already set the ratio.
Covalent (nonmetal + nonmetal): ALWAYS use prefixes. Nonmetals can combine in different ratios, so you need prefixes to tell them apart.
Quick check: Is the first element a metal? → Ionic, no prefixes. Both nonmetals? → Covalent, use prefixes.
