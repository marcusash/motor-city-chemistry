How the Grader Works

1. Formula Normalizer

Before comparing, both Kai's answer and the key are normalized:

"Ca(NO3)2" = "Ca(NO₃)₂" = "ca(no3)2" = "Ca (NO3)2"
Strip spaces, lowercase, convert Unicode subscripts to digits

This handles: case differences, spacing, Unicode vs ASCII subscripts, and minor formatting.

Match type: exact match after normalization

2. Name Normalizer

Compound names are normalized before comparison:

"Iron(III) chloride" = "iron(iii) chloride" = "iron (III) chloride"
"iron(III)chloride" (no space) — also accepted

Rules: lowercase, collapse whitespace, normalize parentheses spacing around Roman numerals.

Match type: fuzzy match — also accepts common alternate names

"ferric chloride" → accepted as alt for "iron(III) chloride"
"cupric oxide" → accepted as alt for "copper(II) oxide"

3. Charge Balance Grader (Q4-type)

For "is this formula neutral?" questions:

Input: student's YES/NO + work shown (cation charge, anion charge, total)
Grade: YES/NO must match key. Work is checked for correct charge values.
If YES/NO is wrong but charges are correct → partial understanding noted

4. Atom Count Grader (Q5-type)

For "count the atoms" questions:

Input: {"Ca": 3, "P": 2, "O": 8}
Key: {"Ca": 3, "P": 2, "O": 8}
Grade: exact numeric match per element

Each element count is independent. Partial credit possible (e.g., got Ca and P right but O wrong).

5. Skill-Level Rollup

The autograder grades per question, then rolls up to per-skill P/NP:

Skill 4.2.6 tested by: Q15, Q16, Q22 (3 questions)
If Kai gets 2/3 or better → P
If Kai gets 1/3 or worse → NP

Threshold: >= 67% correct per skill = P. This matches the teacher's approach of grading by standard, not by individual question.

Chemistry OCR: How GPT-4o Reads Handwriting

The OCR Prompt

GPT-4o vision gets the scanned image + a prompt that says: "This is a completed chemistry practice test. For each numbered question, extract the student's handwritten answer. Parse chemical formulas: subscripts as numbers (Fe2O3), charges as superscripts (Fe2+, CO3^2-). Return JSON: [{questionNumber, answer, confidence}]"

Confidence Scoring

HIGH: GPT-4o is confident in the read. Clear handwriting, unambiguous characters.
MEDIUM: Some ambiguity. Could be "2" or "z", could be "Cl" or "CI".
LOW: Can't reliably read. Crossed-out text, overlapping characters, very faint.

MEDIUM and LOW answers get flagged in the Review step (Step 5) for Kai to confirm or fix.

Chemistry-Specific OCR Challenges

Handwritten chemistry is harder than regular text because:
1. Subscripts and superscripts are small and often ambiguous (is that a subscript 2 or the next element?)
2. Parentheses in formulas like (NH4)2SO4 can be misread
3. Charges like 2+ or 3- are tiny and positioned above the line
4. Element symbols are case-sensitive (Co = cobalt, CO = carbon monoxide)

The Review step is the safety net. Kai sees what the OCR extracted and fixes anything wrong before grading runs. This way his grade reflects what he actually wrote, not what the OCR guessed.
