Design Philosophy

  • Structure preserved exactly: Same number of questions, same standards tested, same format (tables, circle options, show-work spaces)
  • Difficulty slightly reduced in 6.1/6.2: Kai passed 1/18 standards. He needs confidence wins before harder variants.
  • 6.3 kept same difficulty: He left it blank, so the problem isn't "too hard" — it's "hasn't learned yet." Same complexity is fine.
  • Combustion (6.1.6) deliberately easier: C₃H₈ doesn't require the ×2 multiplier that C₆H₁₄ does. Let him nail the algorithm first.
  • Split elements (6.1.7) simpler: 4-substance equation instead of 5-substance. Still tests the concept.
  • Molar mass trap removed: No Fe₃O₄ (where Kai made the cascading error). Uses familiar Al₂O₃ + simple CO₂.
