# Motor City Chemistry

Chemistry tests, quizzes, and worksheets for Kai.

Built by the Grind squad using the same infrastructure as `kai-algebra2-tests`.

## Structure

- `data/` — question bank (JSON)
- `tests/` — exam and quiz HTML
- `docs/` — study guides and reference sheets
- `scripts/` — generation and scoring utilities
- `shared/` — shared components (renderer, scorer)
- `artifacts/` — generated outputs
